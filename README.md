# Kim Laewon Portfolio Rebuild

## 구성
- `index.html`: 포트폴리오 구조
- `style.css`: 전체 디자인, 반응형, 카드 레이아웃
- `main.js`: 스크롤 리빌, 네비게이션 활성화, 배경 파티클

## 적용 방법
1. 기존 GitHub Pages 저장소에서 `.git` 폴더와 폰트 파일은 유지하거나 제거 여부를 따로 판단합니다.
2. 이 폴더 안의 `index.html`, `style.css`, `main.js`를 저장소 루트에 넣습니다.
3. 프로젝트 카드의 `href="#"` 부분을 실제 영상, GitHub, 앱 소개 링크로 바꿉니다.
4. `project-visual` 영역은 실제 썸네일 이미지가 생기면 배경 이미지로 교체합니다.

## 중요한 수정 방향
- 빈 박스형 썸네일을 프로젝트 카드로 변경했습니다.
- 외부 Three.js CDN 없이 동작하도록 순수 Canvas 배경으로 바꿨습니다.
- 모바일 대응, 접근성, 메타 태그, 스크롤 리빌 구조를 보강했습니다.
- 포트폴리오의 정체성을 “모션그래픽 + 코드 기반 인터랙션”으로 선명하게 잡았습니다.
